Four controls would separate the explanations

Proposed experiment · same starting agent, task stream, feedback, and total budget

ArmWhat it can useWhat it tests
A Fixed expertiseStrong expert procedureValue of a good starting method
B Reset + more attemptsExtra inference; no retained stateValue of more computation
C Fixed improverRetained state; unchanged update ruleValue of accumulated experience
D Editable improverRetained state and a revised update ruleAdded value of learning to improve

D must beat C on future work to support a benefit from revising the improver.

SELF-EVOLVING AGENTSDISCUSSION

Test the next task, the old task, and the bill

Proposed evaluation · commit to the test before optimizing the system

QuestionMeasureFailure it can reveal
Does it transfer?New task families and a later time periodSpecialization to development tasks
Does it retain?Earlier-task quality and regression countsNew learning that erases old abilities
Does it pay?Search + training + execution + judgingGains bought by hidden computation
Does it repeat?Independent runs and independent evaluationLucky runs or rubric-specific behavior

A rising best score alone establishes neither durable learning nor accelerating improvement.
