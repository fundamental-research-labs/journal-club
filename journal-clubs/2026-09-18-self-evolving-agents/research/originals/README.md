# Retained primary originals

Acquired September 16, 2026: **24 unmodified primary PDFs and 12 small unmodified repository artifacts**. These files support the [source notes](../sources.md); they are not reproduced experiments. The [manifest](manifest.json) records source URLs, versions/commit pins, license basis, retrieval date, bytes, and SHA-256 hashes.

## Use and provenance

- Paper licenses were checked on canonical arXiv records. CC BY, BY-SA, BY-NC-SA, and BY-NC-ND terms differ; preserve attribution and observe noncommercial/no-derivatives restrictions where stated. These copies are retained for journal-club research, not relicensed.
- AlphaEvolve’s canonical arXiv record declares CC BY-NC-ND 4.0; its PDF also carries a Google DeepMind copyright/all-rights-reserved notice. This original is retained unmodified on the arXiv-declared license basis; no derivative or code permission is inferred.
- Reef and NemoClaw artifacts use Apache-2.0; ScienceBuddy guides/configuration use MIT. Corresponding LICENSE files are included. These licenses cover the repository artifacts, not automatically associated articles, papers, model weights, or datasets.
- Repository captures are deliberately partial. Original Markdown relative links may point to upstream files not retained; preserve the exact originals and use their pinned source URL to navigate the full repository.
- Several arXiv PDFs permit arXiv distribution but do not grant general redistribution rights. These were read temporarily and linked, not retained. The manifest records restricted/failed acquisitions. SEAL, Absolute Zero, and VISTA were retained from previously downloaded official original bytes after version-stamp checks when a versioned download endpoint failed.
- PDF metadata/readability and local hashes were checked. Extraction text, render images, caches, and temporary downloads are outside the repository. Authored notes paraphrase results and link exact tables/sections.
