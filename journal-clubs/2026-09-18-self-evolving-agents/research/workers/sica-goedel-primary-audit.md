# SICA and Gödel-machine primary audit

Audited 2026-09-16 for the self-evolving-agents thesis. These notes distinguish the empirical lineage-selection mechanism used by recent coding agents from the formal acceptance criterion that motivates the “Gödel machine” name.

## A Self-Improving Coding Agent (SICA)

- **Primary source:** Maxime Robeyns, Martin Szummer, and Laurence Aitchison, *A Self-Improving Coding Agent*, [arXiv:2504.15228v2](https://arxiv.org/abs/2504.15228v2), 2025-05-16 revision.
- **Inspection source:** `/tmp/meta-citation-audit.7mmz3G/2025-sica-v2.pdf`; `pdftotext` extraction `/tmp/meta-citation-audit.7mmz3G/2025-sica-v2.txt`. Sections inspected: §3, Algorithm 1, §5.1–5.2, and §6.
- **Mechanism:** SICA stores prior agents and benchmark outcomes in an archive, but each new iteration selects the single best-scoring archived agent as the next meta-agent and base agent (`i_hat = argmax p_j`). That chosen agent receives the archive, identifies an improvement, edits its own scaffold/code, and the resulting child is evaluated and added to the archive (§3, first two paragraphs; Algorithm 1, lines 3–4). The archive therefore informs proposals, but the parent-selection policy follows the current best score rather than sampling diverse or lower-scoring branches as stepping stones.
- **Why it sharpens DGM:** DGM's own §2 calls SICA its closest concurrent system and distinguishes DGM's open-ended archive exploration from greedy single-lineage updating. The bounded wording supported by both papers is: “SICA retains an archive but expands from the best-scoring archived agent; DGM explicitly samples across an archive of variants so temporarily weaker branches can remain available as stepping stones.” Do not describe SICA as having no archive.
- **Limitations stated by SICA:** The authors report difficulty generating novel, feasible modification ideas; early ideas can anchor later variants and create path dependence (§5.1). A failed iteration remains visible as a negative example, but the best-only parent rule does not itself ensure exploration. Short time/cost caps make the utility sensitive to engineering speedups, and the static benchmark set may eventually saturate (§5.1–5.2). The implementation changes prompts and scaffold code, not model weights (§5.2 and §6).
- **Thesis disposition:** Supporting only if DGM already carries the archive/stepping-stone argument. One mechanism sentence prevents the essay from implying DGM invented self-editing coding agents or that all archived approaches explore the archive in the same way. SICA is a direct competing predecessor, not generic infrastructure.

## Gödel Machines

- **Primary source:** Jürgen Schmidhuber, *Gödel Machines: Self-Referential Universal Problem Solvers Making Provably Optimal Self-Improvements*, [arXiv:cs/0309048v5](https://arxiv.org/abs/cs/0309048v5), revised 2006 (original preprint 2003).
- **Inspection source:** `/tmp/meta-citation-audit.7mmz3G/2003-goedel-machine-arxiv.pdf`; `pdftotext` extraction `/tmp/meta-citation-audit.7mmz3G/2003-goedel-machine-arxiv.txt`. Sections inspected: abstract, §2.2, §3.2, §4.1–4.4, and §5.
- **Formal criterion:** The initial program includes a proof searcher that enumerates proof techniques and candidate `switchprog`s. A self-rewrite executes only after the system proves a target theorem: executing the present `switchprog` has higher expected utility than continuing the search for alternative rewrites (§2.2, pp. 3–4; §3.2, items 4–5). The proof is relative to the encoded utility function, axioms, hardware/resource limits, and initial proof-search strategy.
- **Meaning of “global optimality”:** Theorem 4.1 does not claim an empirically best program in an unrestricted absolute sense. It says that, once the target theorem is proved, executing the current rewrite has higher expected utility than waiting for the same proof process to find another rewrite (§4.1, pp. 11–12). The paper explicitly notes that finding such proofs may be difficult (§4.4).
- **Why it sharpens DGM:** DGM §3 replaces this proof-gated switch with empirical evaluation: candidate agent changes are accepted and retained based on coding-benchmark evidence, while archive-based exploration addresses local-optimum risk. A safe sentence is: “The Gödel machine is a formal proof-gated ideal; DGM borrows the self-referential goal but substitutes benchmark selection and open-ended archive search, so its ‘Gödel’ label does not confer the original optimality guarantee.”
- **Thesis disposition:** Supporting only as conceptual foundation for the name and the proof-versus-empirical contrast. It is not empirical evidence for agent improvement and should not be counted as an evaluated self-evolving-agent system.
