# Memory, skills, and context optimization: discovery lane

**Run/cutoff:** 2026-09-16 (search performed 2026-09-16). **Scope:** persistent memory, skill creation/curation, context/playbook optimization, and evaluations of retention, transfer, forgetting, and contamination for self-evolving LLM agents. Existing coverage was read first: [WikiSkill](../notes/2026-wikiskill.md), [Library Drift](../notes/2026-library-drift.md), and [AgentStream](../notes/2026-agentstream.md). This is a discovery handoff, not a final shortlist. Abstract-level findings below are leads unless marked as substantively read.

## Strongest additions for screening

1. **MemSkill** — a closed loop in which a controller selects memory skills, an executor writes memories, and a designer evolves skills from hard cases. It is the clearest bridge between memory operations and reusable skill evolution, with evaluations across LoCoMo, LongMemEval, HotpotQA, and ALFWorld. Strong conceptual fit; quantitative details and controls still need full-text verification.
2. **SkillOS** — learns a curator policy over an external SkillRepo from grouped task streams and delayed downstream feedback. It directly tests whether curation generalizes across executor backbones and domains, making it a useful complement to WikiSkill/Library Drift. Abstract-level only here.
3. **SelfMem** — lets an agent explore and refine its own memory strategy through tools and feedback rather than fixing storage/retrieval heuristics. Reports large gains on BEAM at 100K–1M tokens; benchmark and judge configuration need audit before using the percentages.
4. **MemRL** — separates a frozen LLM from a plastic episodic memory and learns retrieval utility (Q-values) from environmental feedback. It is a particularly clean stability/plasticity mechanism and evaluates HLE, BigCodeBench, ALFWorld, and Lifelong Agent Bench. Abstract-level only; inspect cost and task-stream protocol.
5. **Ground Truth First** — an evaluation contribution rather than a memory architecture, but highly consequential: seeded facts with validity intervals produce a longitudinal test where rankings reverse with tenure (curated map 96%→72%, provenance graph 90% at nine weeks). The result directly challenges short-horizon memory leaderboards and should be checked against the released harness.

## Candidate evidence families

Each entry gives canonical metadata, access depth, and a preliminary lead. “Abstract screen” means the arXiv metadata/abstract was inspected; it is not evidence of a full methods/results review.

### Existing corpus and direct comparators

- **WikiSkill (2026), Liyan Tang et al.** Canonical: https://arxiv.org/abs/2608.27454 (v1 Aug 27, 2026; HTML https://arxiv.org/html/2608.27454v1). Preprint, full relevant methods/results/appendices read in existing note. Evidence family: persistent wiki + skill evolution. Existing note reports Qwen-3.5-9B macro accuracy 29.9→47.4, but OfficeQA regression 30.2→28.5; five benchmarks, three evolution runs, held-out splits. Download: arXiv PDF; retention permission/license unknown, so retain link rather than assume redistribution. Existing note: [2026-wikiskill.md](../notes/2026-wikiskill.md).

- **Library Drift / Ratchet (2026), Xing Zhang et al.** Canonical: https://arxiv.org/abs/2605.19576 (v3 Jul 29, 2026; code https://github.com/amazon-science/Self-Evolving-Agents-Ratchet). Preprint + code; existing note reads §§5–7/Table 1. Evidence family: bounded skill storage, routing, retirement. Default late-window gain +0.328±0.018 SD; harsh retirement −0.019±0.010; repeated MBPP tasks, one model, unmatched cost. Code repository license should be checked before retaining files. Existing note: [2026-library-drift.md](../notes/2026-library-drift.md).

- **AgentStream (2026), Dong Yan et al.** Canonical: https://arxiv.org/abs/2608.00155 (v1 Jul 31, 2026). Preprint; existing note reads framework/setup/main results. Evidence family: stream/order effects across memory and skill methods. Six benchmarks × 50 tasks, three ordering seeds; ACE, A-Mem, ReasoningBank, AutoSkill. GPT-5.4 A-Mem interleaved 50.4 vs vanilla 45.8, while AutoSkill isolated regresses to 42.8; Claude Opus 4.7 ACE isolated 67.0 but interleaved 61.9. Existing note: [2026-agentstream.md](../notes/2026-agentstream.md). Read seed tables before causal claims.

### Memory and skill-learning mechanisms

- **MemSkill: Learning and Evolving Memory Skills for Self-Evolving Agents (2026), Haozhen Zhang et al.** Canonical: https://arxiv.org/abs/2602.02474 (v1 Feb 2, 2026). Preprint and public implementation lead via https://github.com/ViktorAxelsen/MemSkill; repository states Apache-2.0. Abstract screen. Evidence family: learnable memory-operation skills. Controller selects skills; executor produces skill-guided memories; designer mines hard cases to refine/add skills. Evaluates LoCoMo, LongMemEval, HotpotQA, ALFWorld and reports generalization across settings. Verify exact split, backbone, judge, and transfer claims.

- **SkillOS: Learning Skill Curation for Self-Evolving Agents (2026), Siru Ouyang et al.** Canonical: https://arxiv.org/abs/2605.06614 (v1 May 7, 2026). Preprint; abstract screen. Evidence family: reinforcement-learned skill curator. Frozen executor retrieves/applies skills while trainable curator updates external SkillRepo from grouped task streams with delayed feedback; authors report gains over memory-free and memory baselines and cross-backbone/domain generalization. Download arXiv PDF; license unknown. Needs full-text audit for reward construction and leakage between related streams.

- **MUSE-Autoskill (2026), Huawei Lin et al.** Canonical: https://arxiv.org/abs/2605.27366 (v1 May 26, 2026). Preprint; abstract screen. Evidence family: skill lifecycle management. Creation, memory, organization, unit-test/runtime evaluation, and refinement; reports initial SkillsBench evidence for success, efficiency, reuse, and cross-agent transfer. Download arXiv PDF; license unknown. Closely related to WikiSkill but likely different benchmark/protocol; deduplicate as a family only after reading.

- **MemRL: Self-Evolving Agents via Runtime Reinforcement Learning on Episodic Memory (2026), Shengtao Zhang et al.** Canonical: https://arxiv.org/abs/2601.03192 (v1 Jan 6, 2026). Preprint; abstract screen. Evidence family: utility-learned episodic retrieval. Two-phase retrieval first uses semantic relevance then learned Q-values refined by environmental feedback; frozen LLM, plastic memory. Reports improvements on HLE, BigCodeBench, ALFWorld, Lifelong Agent Bench. Verify whether feedback is task reward, judge reward, or execution signal and inspect cost/online leakage.

- **ReasoningBank: Scaling Agent Self-Evolving with Reasoning Memory (2025), Siru Ouyang et al.** Canonical: https://arxiv.org/abs/2509.25140 (v1 Sep 29, 2025; check arXiv history for later versions). Preprint; abstract screen; also named in AgentStream. Evidence family: distilled successful/failed reasoning plus memory-aware test-time scaling (MaTTS). Reports gains over raw-trajectory and success-only memory on web browsing/software engineering. Verify held-out stream design, self-judging reliability, and compute parity.

- **A-MEM: Agentic Memory for LLM Agents (2025), Wujiang Xu et al.** Canonical: https://arxiv.org/abs/2502.12110; NeurIPS 2025 paper PDF https://papers.neurips.cc/paper_files/paper/2025/file/19909c36f51abc4856b4560aff3d36d6-Paper-Conference.pdf; code https://github.com/agiresearch/A-mem and evaluation code https://github.com/WujiangXu/AgenticMemory. Published/accepted NeurIPS 2025; abstract screen. Evidence family: Zettelkasten-style dynamic indexing/linking and memory evolution. Claims gains over memory baselines across six foundation models. Inspect benchmark contamination and version (arXiv history differs from conference copy); code license unknown.

- **Mem-α: Learning Memory Construction via Reinforcement Learning (2025), Yu Wang et al.** Canonical: https://arxiv.org/abs/2509.25911 (v1 Sep 30, 2025). Preprint; abstract screen. Evidence family: RL for deciding what/how/when to store. Uses core, episodic, semantic memory tools; reward is downstream QA over interaction history; trained max 30k tokens and reports generalization beyond 400k tokens. Verify training/evaluation overlap, sequence construction, and whether the 13× extrapolation is robust.

- **Memory-R1 (2025), Sikuan Yan et al.** Canonical: https://arxiv.org/abs/2508.19828 (v1 Aug 27, 2025). Preprint; abstract screen. Evidence family: learned memory manager + answer agent. Manager performs ADD/UPDATE/DELETE/NOOP and answer agent retrieves/reasons; PPO/GRPO outcome-driven RL with as few as 152 QA pairs. Reports generalization over question types/backbones. High relevance to update policy; inspect small-data protocol and reward/judge dependence.

- **SelfMem: Self-Optimizing Memory for AI Agents (2026), Shu Yang et al.** Canonical: https://arxiv.org/abs/2607.03726 (v1 Jul 4, 2026). Preprint; abstract screen. Evidence family: agent-learned memory strategy. Agent explores, evaluates, and refines memory operations with feedback; reports BEAM gains of 48.7%, 40.8%, 41.9% over strongest baseline at 100K, 500K, 1M tokens and additional model-guided refinement. These are abstract-reported percentages; inspect BEAM version, judge, baseline, and token budget.

- **EverMemOS: A Self-Organizing Memory Operating System for Structured Long-Horizon Reasoning (2026), Chuanrui Hu et al.** Canonical: https://arxiv.org/abs/2601.02163 (v1 Jan 5, 2026); code https://github.com/EverMind-AI/EverMemOS. Preprint + code; abstract screen. Evidence family: episodic trace → semantic consolidation → reconstructive recollection. Reports SOTA on LoCoMo and LongMemEval, plus PersonaMem v2 profile study. Verify exact scores, judge model, and whether “OS” components are independently ablated. Code license not checked.

### Context and prompt/playbook optimization

- **ACE: Agentic Context Engineering (2025), Qizheng Zhang et al.** Canonical: https://arxiv.org/abs/2510.04618 (v1 Oct 6, 2025). Preprint; abstract screen; already used in AgentStream. Evidence family: evolving structured playbooks. Generation/reflection/curation avoids context collapse and brevity bias; abstract reports +10.6% agents, +8.6% finance, and AppWorld challenge results with lower adaptation latency/rollout cost. Read full paper for baseline, task splits, and online/offline distinction.

- **GEPA: Reflective Prompt Evolution Can Outperform Reinforcement Learning (2025), Lakshya A. Agrawal et al.** Canonical: https://arxiv.org/abs/2507.19457 (v1 Jul 25, 2025); code https://github.com/gepa-ai/gepa. Preprint; abstract screen. Evidence family: Pareto-guided natural-language prompt/context evolution. Across six tasks reports +6% average vs GRPO, up to +20%, and up to 35× fewer rollouts; +12% AIME-2025 vs MIPROv2. Need full-text audit of search budgets and scorer/reward setup; “outperform RL” is task-conditional.

- **Reflection in the Dark / VISTA (2026), Shiyan Liu et al.** Canonical: https://arxiv.org/abs/2603.18388 (v1 Mar 19, 2026). Preprint; abstract screen. Evidence family: critique of reflective prompt optimization. Reports GEPA degradation on defective GSM8K seed (23.81→13.50%) and proposes labeled hypotheses, parallel verification, random restarts/epsilon-greedy; VISTA recovers 87.57% and beats baselines on GSM8K/AIME2025. Important counterevidence to monotonic prompt evolution; verify whether comparisons use matched calls and same seeds.

- **When Self-Evolution Backfires: Pre-Commit Gating against Skill Contamination (2026), Linfang Shang et al.** Canonical: https://arxiv.org/abs/2608.05810 (v1 Aug 6, 2026). Preprint; abstract screen. Evidence family: skill contamination and admission gates. Authors report a non-monotonic pool-size phase transition, irreversibility of descendant contamination, and a three-critic Verifier-as-Gatekeeper reaching 72% pass@1 with ~5× smaller pool plus positive transfer across four backbones/another benchmark. Strong complement to Library Drift; full-text audit needed for task counts, selection, and verifier independence.

- **PILOT in the Loop: Live Self-Improvement for Long-Horizon Agents (2026), Yang Xiao et al.** Canonical: https://arxiv.org/abs/2608.26530 (v1 Aug 27, 2026). Preprint; abstract screen. Evidence family: live steering plus live skill/memory evolution. Abstract reports first rank in five of six configurations, up to +9.8 points on Terminal-Bench 2.0, self-improvement gains 14.6/12.4 points, and 42.9/47.4% lower output tokens on two backbones. New frontier lead; verify frozen splits, supervisor overhead, and whether “self-improvement” includes extra model calls.

- **Recuris: Recursive Experiential–Working Memory Evolution for Long-Horizon Agent Harnesses (2026), Gen-Verse.** Canonical code/release: https://github.com/Gen-Verse/Recuris (initial release Aug 2026; paper metadata not located in this pass). Practitioner/code artifact; abstract/README screen. Evidence family: evolved skill-memory packages transferred to frozen downstream agents. README reports larger gains on longer-horizon τ²-Retail/τ²-Airline and SkillFlow/Terminal-Bench, with paired bootstrap CIs on some cells. Treat as measured practitioner evidence pending paper and protocol inspection; repository license/version should be recorded before retention.

### Evaluation and benchmark families

- **MemoryAgentBench (2025/ICLR 2026), Yuanzhe Hu, Yu Wang, Julian McAuley.** Canonical: https://arxiv.org/abs/2507.05257; ICLR PDF https://openreview.net/pdf?id=DT7JyQC3MR; code likely https://github.com/HUST-AI-HYZ/MemoryAgentBench. Preprint/conference; abstract screen. Evidence family: incremental multi-turn evaluation. Four competencies are accurate retrieval, test-time learning, long-range understanding, and selective forgetting; authors report current systems do not master all four. Read code because later atlas inspection suggests the “selective forgetting” label may not match implementation.

- **Mem2ActBench (2026), Yiting Shen et al.** Canonical: https://arxiv.org/abs/2601.19935 (v1 Jan 13, 2026). Preprint; abstract screen. Evidence family: active memory use in tool execution. 2,029 sessions average 12 user–assistant–tool turns; 400 tool-use tasks; human evaluation says 91.3% strongly memory-dependent; seven memory frameworks remain inadequate at parameter grounding. Verify synthetic reverse-generation and judge protocol.

- **Ground Truth First (2026), Quentin Spencer.** Canonical: https://arxiv.org/abs/2607.21962 (v1 Jul 24, 2026); Veracium release link is given in the paper/author repository (not independently located). Preprint; abstract screen. Evidence family: seeded longitudinal benchmark. About 380 questions/15 types, five memory architectures, three replicates and two horizons; rankings invert at three vs nine weeks, and write-stage quality predicts downstream failure (24% vs 2%). High-value evaluation lead; inspect generator license and independent re-judging.

- **LongMemEval (2025), Di Wu et al.** Canonical paper: https://proceedings.iclr.cc/paper_files/paper/2025/file/d813d324dbf0598bbdc9c8e79740ed01-Paper-Conference.pdf; code/data https://github.com/xiaowu0162/LongMemEval. ICLR 2025; source and repository license should be checked (repository displays license). Evidence family: 500 multi-session questions covering extraction, multi-session reasoning, knowledge updates, temporal reasoning, abstention. Foundational benchmark, but its short/medium horizons and LLM judging limit direct claims about lifelong self-evolution.

- **AgentMemoryBench (2026), Solomoon et al.** Canonical: https://github.com/solomoon313/AgentMemoryBench; paper PDF in repository (`AgentMemoryBench_v1_for_NIPS2026.pdf`). Preprint/code artifact, abstract/README screen; repository license visible but not independently recorded. Evidence family: unified continual memory benchmark. Six interactive tasks spanning system and personal memory; offline, online, replay, transfer, and other modes with learning-gain/stability-loss/forgetting metrics. Promising evaluation complement; verify frozen test partitions and task contamination.

- **From Storage to Experience: A Survey on the Evolution of LLM Agent Memory Mechanisms (ACL Findings/ICLR MemAgents, 2026), Feishu Luo et al.** Canonical maintained index: https://github.com/FeishuLuo/Evolving-LLM-Agent-Memory-Survey (paper link in repository; not separately verified). Survey/repository; abstract/index screen only. Evidence family: taxonomy and discovery index, claims 140+ papers and 40+ benchmarks across storage, reflection, and experience. Useful citation expansion, not primary evidence; do not use survey counts as measured results.

Coverage is strongest for 2025–September 2026 memory/skill mechanisms and evaluation. It overlaps the existing WikiSkill/Library Drift/AgentStream lane but adds learned curation, learned retrieval utility, self-optimizing memory, active tool use, and long-horizon validity. Historical baselines (Reflexion, Voyager, SEAL, SICA, DGM) were already indexed in the session and were not duplicated here. Two expansion passes after the initial mechanism searches produced mostly duplicate families or non-primary repositories. Remaining gaps are: full-text verification of the strongest 2026 papers; matched-cost and judge-independent comparisons; evidence for selective forgetting and deletion; cross-domain transfer under changing tools/interfaces; and licenses/retention permissions for code and benchmark data. Search snippets were used only for discovery, never as sole support for a verified quantitative claim.

## Handoff caveats

The existing session’s clearest empirical pattern remains non-monotonicity: WikiSkill and AgentStream show configuration-specific regressions, Library Drift shows lifecycle sensitivity, and the new contamination paper claims post-hoc rollback can be insufficient. The new positive results should therefore be framed as mechanism- and benchmark-specific until full methods, controls, costs, and held-out transfer are read. Memory QA benchmarks (LongMemEval, LoCoMo, BEAM) do not automatically establish improved task execution; Mem2ActBench is especially relevant for that gap. Abstract access dominates this lane, so no new source should enter the final shortlist without primary full-text verification.
