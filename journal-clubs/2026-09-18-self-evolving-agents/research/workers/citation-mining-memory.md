## One expansion and prioritization

I expanded the strongest omission, Trace2Skill, to its authors' official GitHub repository (https://github.com/Qwen-Applications/Trace2Skill) after the arXiv lookup. The repository documents the parallel trajectory-analysis, patch-consolidation pipeline and links the exact arXiv identifier, strengthening source verification while leaving quantitative claims unverified here. The top three additions are **EvoSkill**, **SkillOpt**, and **Trace2Skill**: together they close the specific missing comparison set that WikiSkill itself names, and they are more decision-relevant to this session than another generic memory benchmark. MemGPT is a useful historical fourth candidate only if the session needs a longer memory lineage.

## Limits and stop reason

This was a bounded three-seed pass with at most twelve citation edges; five edges are recorded because the remaining seed citations were already represented in the register (ReasoningBank, ACE, AutoSkill, LongMemEval/LoCoMo, and related benchmarks) or were generic infrastructure references. Citation context was used to identify roles and omissions, never as verification of the cited papers' findings. No copyrighted source text was retained. I stopped after one expansion because the named skill-evolution comparison gap was clear, additional citations were redundant with existing keys, and the requested refinement budget was reached; full-text screening of the three new candidates remains for a later coordinator pass.

Coordinator QC: the Trace2Skill repository lookup verifies the cited source; it is not another backward-citation generation. WikiSkill §1 paragraph beginning “A key design question” and §6 “Experience-Driven Agent Skill Evolution” explicitly name all three missing skill comparators. Those contexts were independently checked.
