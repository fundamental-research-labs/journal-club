# Citation screening: skill-evolution baselines

Screened 2026-09-16 against the existing ten-source shortlist and the preparation cutoff. I read the current primary arXiv PDF for each source (downloaded to temporary storage and not retained in the repository); arXiv metadata and license pages were also checked. Ratings use the shortlist rubric: relevance (R), evidence (E), novelty (N), teaching value (T), and coverage contribution (C), with H/M/L/U.

## SkillOpt

**Metadata/access.** Yifan Yang, Ziyang Gong, Weiquan Huang, Qihao Yang, Ziwei Zhou, Zisu Huang, Yan Li, Xuemei Gao, Qi Dai, Bei Liu, Kai Qiu, Yuqing Yang, Dongdong Chen, Xue Yang, and Chong Luo, “SkillOpt: Executive Strategy for Self-Evolving Agent Skills,” arXiv:2605.23904v2, first posted 2026-05-22, v2 2026-05-25, 27 pages. Canonical: https://arxiv.org/abs/2605.23904v2. PDF/download: https://arxiv.org/pdf/2605.23904v2. Code link in the paper: https://aka.ms/skillopt. The arXiv page gives a nonexclusive-distribution license; no repository copy is retained. Full PDF read, including appendices.

**What was tested.** A frozen target model is adapted by an offline optimizer that proposes bounded add/delete/replace edits to one skill document, with strict held-out selection gating, rejected-edit memory, and an epoch-wise slow/meta update (§§3.1–3.7, Algorithm 1). Direct-chat experiments cover six benchmarks (SearchQA, SpreadsheetBench, OfficeQA, DocVQA, LiveMathematicianBench, ALFWorld) and seven target models; Codex and Claude Code cover five compatible benchmarks. Table 1 counts 52 model–benchmark–harness cells. Default training is four epochs, rollout batch 40, reflection minibatches of 8, 16 analyst workers, textual learning-rate budget 4 with cosine decay; bounded pools scale to 35 LiveMath training items and 39 ALFWorld tasks (§4, Table 6). The paper reports no independent-run intervals/SDs for the main matrix. GPT-5.5 direct-chat average is 58.8→82.3 (+23.5 points), and the method is best/tied in 52/52 cells (Table 1, §4.1); these are reported point estimates, not uncertainty estimates. Training tokens range 20.8M–213.8M across six GPT-5.5 runs (Table 6).

The strongest teaching point is a clean comparison of persistent skill optimization against Trace2Skill, EvoSkill, GEPA, TextGrad, human, and one-shot skills under a fixed scorer (§4, Table 1). Limits are one fixed split seed (42), no reported independent-run uncertainty, substantial and uneven token budgets, and a benchmark suite whose largest gains are procedural. The paper itself frames the optimizer as a single-domain artifact and calls for broader libraries and reward-free gates (§5). **Rubric: R H; E M; N H; T H; C H. Decision: SHORTLIST, replacing Shopify in the ten if the session prioritizes inspectable comparative efficacy; otherwise retain Shopify for its production perspective and hold SkillOpt as the first reserve.**

## EvoSkill

**Metadata/access.** Salaheddin Alzubi, Noah Provenzano, Jaydon Bingham, Weiyuan Chen, and Tu Vu, “EvoSkill: Automated Skill Discovery for Multi-Agent Systems,” arXiv:2603.02766v1, posted 2026-03-03 (work-in-progress preprint). Canonical: https://arxiv.org/abs/2603.02766v1. PDF/download: https://arxiv.org/pdf/2603.02766v1. The arXiv page lists CC BY 4.0; no full text is retained in the repository. Full PDF read, including Appendix C/D and the stated variance limitation.

**What was tested.** Executor, failure-analysis proposer, and skill-builder agents evolve structured skill folders while Claude Code with Opus 4.5 remains frozen (§§2.1–2.3). Data are stratified into disjoint train, validation, and held-out test partitions. OfficeQA has 246 questions; the validation set is 17 examples (about 7%), training conditions are 5/10/15% (12/24/36 examples), and each is evolved for 1.5 epochs. SealQA uses 111 questions, a 10% training split, and 1.5 epochs (§§3.1–3.2). The skill-merge condition combines skills from independent runs. Table 1 reports exact-match OfficeQA baseline 60.6 versus 63.4/65.8/64.5 for 5/10/15% and 68.1 for merge (the prose headline says 67.9; this internal discrepancy should be shown rather than silently resolved). SealQA rises 26.6→38.7 (+12.1), and a skill transferred to 128 sampled BrowseComp examples rises 43.5→48.8 (+5.3, §3.3). Each configuration was evaluated in a single run because of Opus cost; the paper reports no SD, confidence interval, or token/GPU ledger (footnote to Table 1, §3.1.3).

The failure-driven, interpretable skill-folder mechanism is a useful baseline and makes a good discussion contrast with SkillOpt’s bounded edits. Evidence is constrained by tiny validation data, single-run estimates, two benchmarks, one target model/harness, and the OfficeQA merge selection; the authors call for broader domains (§5). **Rubric: R H; E M; N M; T H; C M. Decision: RESERVE.** It is already a direct competitor in SkillOpt’s Table 1 and overlaps WikiSkill’s persistent skill mechanism; use it as the cited baseline and as a close alternative to the ten rather than spending a separate slot.

## Trace2Skill

**Metadata/access.** Jingwei Ni, Yihao Liu, Xinpeng Liu, Yutao Sun, Mengyu Zhou, Pengyu Cheng, Dexin Wang, Erchao Zhao, Xiaoxi Jiang, and Guanjun Jiang, “Trace2Skill: Distill Trajectory-Local Lessons into Transferable Agent Skills,” arXiv:2603.25158v5, first posted 2026-03-26, v5 2026-06-04; the record labels it “Work in Progress. May version add more experiments.” Canonical: https://arxiv.org/abs/2603.25158v5. PDF/download: https://arxiv.org/pdf/2603.25158v5. Code: https://github.com/Qwen-Applications/Trace2Skill. arXiv lists CC BY 4.0; no full text was retained by this worker. Full PDF read, including appendices.

**What was tested.** A frozen ReAct agent generates success/failure traces; parallel analysts propose patches and a hierarchical merge produces one skill directory (§§2.1–2.4). Main SpreadsheetBench-Verified evaluation splits 400 samples into 200 evolution and 200 held-out test problems, with OOD WikiTableQuestions (2,810) and HiTab (1,585); Qwen3.5-122B-A10B and 35B-A3B serve as author/users. Results average three seeds (41, 42, 43); Table 7 reports paired-delta SDs, and the paper gives SD ranges of 1.1–2.4 for DAPO-Test, 1.8–3.4 for AIME’26, and 0.034–0.139 for DocVQA ANLS (Appendix A, Table 7). In Table 1, Qwen 35B-authored Creation +Error transfers to Qwen 122B with +57.65 WikiTQ points; math uses 400 DAPO evolution and 100 held-out DAPO plus 30-problem AIME’26 avg@8 (Table 2); DocVQA evolves on 50 examples and tests the remaining 5,299 (Table 3). Approximate total expenditure is 20,000 GPU hours on 8×A100 nodes (Appendix A). The authors’ limitation is a sampled validation of only 32 questions and costly combinatorial patch selection (§6).

This is the strongest of the three for transfer teaching: it separates in-distribution from OOD tasks, model-family transfer, sequential-edit and ReasoningBank comparisons (Tables 4, 8–11), and reports dispersion. Caveats include self-evolution (same model authors and uses skills), many comparisons and task-level dependence, and a large aggregate compute budget. **Rubric: R H; E H; N H; T H; C M. Decision: RESERVE.** It overlaps WikiSkill’s trajectory-to-skill story and SkillOpt’s direct baseline matrix; promote it over Shopify only if cross-model/OOD transfer becomes the session’s central question.

## Screening decision relative to the existing ten

SkillOpt is the only omission that materially improves the current ten’s comparative evidence: it can replace Shopify when a method-centered ten is desired. EvoSkill and Trace2Skill remain reserves because their mechanisms and results are already represented through WikiSkill and SkillOpt’s baseline comparisons, while Trace2Skill is especially useful as a transfer-focused companion. None of the three establishes long-horizon, domain-general, accelerating recursive self-improvement; all operate on frozen models and external skill artifacts.
