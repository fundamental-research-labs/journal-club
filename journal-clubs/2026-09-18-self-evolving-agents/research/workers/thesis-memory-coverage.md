## Verified findings and thesis additions

The thesis should add a sharper distinction between *runtime plasticity* and *general improvement*. MemRL's frozen model and utility updates provide a clean stability mechanism, but its own limitations say that low-similarity task streams can turn memory into reflection-like behavior and that credit assignment remains unresolved. The claim should therefore say that persistent memory can improve recurring or sufficiently dense task streams, not that it establishes broad self-acceleration.

MemSkill adds a missing mechanism bridge: the object that evolves can be the memory-writing procedure itself. Its closed loop separates trace-specific memory from a shared skill bank (§3.1, lines 123–125), and its hard-case designer can roll back degraded skill banks (§3.4, lines 158–166). This supports the thesis's “what experience changes” framing, while the two-model transfer and API-based components leave static expertise, total compute, and repeated-cycle durability unresolved.

Ground Truth First should be used as a methodological challenge to the current evidence base. Its tenure result and full-history baseline show that an apparent memory gain may be a horizon/cost artifact: the tested layered system saves read tokens, but does not win judge-independently at nine weeks. Add explicit tests for validity intervals, provenance, old-task retention, full-history and recency controls, and report read/write/update cost over tenure.

The strongest missing evidence remains a cost-matched, multi-cycle comparison of (a) fixed expert skill, (b) extra attempts, (c) persistent memory with fixed update rules, and (d) an agent that can revise its update rule, evaluated on novel domains and old-task retention. None of the newly inspected sources establishes increasingly efficient improvement across cycles.
