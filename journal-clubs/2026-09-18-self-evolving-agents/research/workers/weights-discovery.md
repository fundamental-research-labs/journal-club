# Weights and learning-process discovery

Run date/cutoff: 2026-09-16 (America/Los_Angeles), with publication/version dates checked against primary pages where available. Scope: methods that change model parameters, generate training curricula/data, learn at test time, or offer close alternatives (prompt/skill/harness evolution) relevant to self-evolving agents. This is a discovery lane, not a final shortlist. Search used 12 queries plus citation/project-page expansions; no recursive delegation. Stop condition: two expansion passes produced mostly duplicates or surveys.

## Highest-priority five families

1. **SEAL (Self-Adapting Language Models)** — Zweiger et al., arXiv:2506.10943 (2025-06-12), NeurIPS 2025 paper PDF: https://arxiv.org/abs/2506.10943 ; https://papers.neurips.cc/paper_files/paper/2025/file/6b41e04c41726e2a60e456d0a2b961ab-Paper-Conference.pdf ; code: https://github.com/mithilai/SEAL . Full paper/abstract inspected via OpenReview and NeurIPS PDF. The model emits self-edits containing synthetic data and optimization directives; an outer RL loop rewards downstream performance after the inner SFT update. It is direct evidence for persistent weight adaptation, but experiments are task-local (knowledge incorporation/few-shot generalization), not open-ended recursive improvement. **License:** code license should be checked before retention; paper is publicly accessible, no local copy saved.

2. **Absolute Zero Reasoner** — Zhao et al., arXiv:2505.03335 (2025-05-06), project/code: https://arxiv.org/abs/2505.03335 ; https://github.com/LeapLabTHU/Absolute-Zero-Reasoner ; project: https://andrewzh112.github.io/absolute-zero-reasoner/ . Abstract, project page, and code README inspected; full quantitative paper audit remains pending. A single model proposes tasks optimized for learnability and solves them with verifiable rewards, removing curated training data. The claim is zero external data, not zero prior pretrained knowledge; repository warns current `main` differs from the paper branch. **License:** repository license/version should be recorded before saving code.

3. **R-Zero** — Huang et al., arXiv:2508.05004 (2025-08-07), ICLR 2026 acceptance announced 2026-01-23; https://arxiv.org/abs/2508.05004 ; PDF/open review: https://openreview.net/pdf?id=oSGOE5z2iU ; code: https://github.com/Chengsong-Huang/R-Zero . Abstract and official README inspected; detailed methods/results pending. Challenger and Solver co-evolve: the Challenger generates near-frontier tasks and Solver learns to solve them, yielding an autonomous curriculum. Abstract reports Qwen3-4B-Base gains of +6.49 math and +7.54 general reasoning (benchmark definitions and controls require full-paper verification). **License:** code license not recorded here; inspect before retaining.

4. **TTRL (Test-Time Reinforcement Learning)** — Zuo et al., arXiv:2504.16084 (2025-04-22), OpenReview PDF: https://arxiv.org/abs/2504.16084 ; https://openreview.net/pdf/3ff432e912f7ed9bbbacf9a7a16d7e5af88d721a.pdf ; code: https://github.com/PRIME-RL/TTRL . Full PDF conclusion and abstract inspected. Majority-vote rewards on unlabeled test data drive RL updates; abstract reports Qwen-2.5-Math-7B AIME 2024 pass@1 improvement of approximately 159%. This is a strong test-time/weight-update bridge, but consensus can amplify shared errors and “test-time” training risks contamination; inspect split and compute accounting before using the number.

5. **Self-Evolving Curriculum (SEC)** — Chen et al., arXiv:2505.14970 (2025-05-20), https://arxiv.org/abs/2505.14970 . Abstract inspected. A learned non-stationary multi-armed-bandit curriculum policy selects problem categories during RL, using absolute advantage as a learning-gain proxy; authors report better in-domain and harder OOD reasoning across planning, induction, and math. It is a useful controlled curriculum baseline, though the curriculum policy is an additional learned component rather than a recursively improving agent.

## Strongest counterevidence and interpretation cautions

- Recursive synthetic training can collapse when generated data replaces real data (Shumailov/Nature; Alemohammad), while accumulation and verification may stabilize it. Therefore “self-generated data” is not a sufficient mechanism; provenance, mixture, filtering, and held-out evaluation are causal variables.
- Self-refinement, Voyager, GEPA, and many agent systems improve outputs or external state with frozen weights. They are credible alternatives, but should not be labeled parameter learning or recursive self-improvement without specifying the editable state.
- TTRL's majority vote is a self-derived reward. It can improve average scores while preserving shared model errors; verify unlabeled/test split separation, number of samples, compute, and independent evaluation before treating the reported +159% as general learning.
- Self-play papers often compare to weak or differently budgeted baselines. Absolute Zero/R-Zero need full-table checks for starting model, data exclusions, verifier dependence, seed count, and whether “zero data” still relies on pretrained linguistic/math priors.
- Continual-learning results vary with task order and replay. CurLL, TiC-LM, and MoE-CL are useful because they quantify forgetting/transfer; a single end-task score cannot establish durable improvement.
- Reward hacking and evaluation gaming are credible process-level failure modes: Anthropic’s reward-tampering work https://www.anthropic.com/research/reward-tampering and NIST’s evaluation-cheating background https://www.nist.gov/caisi/cheating-ai-agent-evaluations/1-background-ai-models-can-cheat-evaluations motivate sealed evaluators and independent held-out tasks.
