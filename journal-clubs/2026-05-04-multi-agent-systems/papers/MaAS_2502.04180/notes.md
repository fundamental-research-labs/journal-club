# Notes

## Why it matters

MaAS is a concrete architecture-search answer to static multi-agent pipelines. It frames agent workflow selection as a cost-aware, query-conditioned search problem rather than prompt tuning a single design.

## When to cite/use

Cite for automated multi-agent design, agent workflow search, agentic supernets, query-dependent resource allocation, and efficiency comparisons against fixed multi-agent baselines.

## Key terms

- MaAS
- agentic supernet
- agentic operator
- controller network
- early-exit operator
- textual gradient
