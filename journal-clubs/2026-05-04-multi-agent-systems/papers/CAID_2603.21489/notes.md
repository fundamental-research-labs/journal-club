# Notes

## Why It Matters
CAID is a practical blueprint for multi-agent coding systems that need shared-repository progress without concurrent-edit chaos. Its main lesson is that parallelism needs software-engineering primitives: dependency-aware delegation, isolated branches, explicit merge, and executable verification.

## When To Cite
Cite it for asynchronous software-engineering agents, `git worktree` isolation, branch-and-merge multi-agent coordination, multi-agent coding benchmarks, and the limits of simply giving one agent more iterations.

## Key Terms
CAID; centralized asynchronous isolated delegation; branch-and-merge; manager agent; engineer agents; dependency graph; `git worktree`; `git commit`; `git merge`; self-verification; PaperBench; Commit0-Lite.
