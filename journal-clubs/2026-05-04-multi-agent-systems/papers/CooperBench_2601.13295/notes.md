# Notes

## Why it matters

CooperBench is useful evidence against assuming that multiple coding agents automatically improve productivity. It isolates a practical failure mode: agents can write plausible code independently but fail when their patches must integrate.

## When to cite/use

Cite when discussing multi-agent coding benchmarks, coordination overhead, shared-repository agent workflows, communication limits, or why solo baselines are necessary for agent-team evaluations.

## Key terms

- CooperBench
- Coop vs. Solo
- coordination gap
- spatial vs. semantic coordination
- commitment and expectation failures
- partial observability
