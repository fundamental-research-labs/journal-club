# Notes

This paper matters because it gives a compute-controlled counterweight to claims that multi-agent decomposition is inherently better for reasoning.

Use it when evaluating agent frameworks, normalizing test-time compute, or explaining why a single stronger reasoning trace may beat several shorter coordinated traces. It is especially relevant for multi-hop QA and context-budget discussions.

Key terms: thinking-token budget, Data Processing Inequality, context degradation, Sequential MAS, Debate MAS, SAS-L, FRAMES, MuSiQue.
