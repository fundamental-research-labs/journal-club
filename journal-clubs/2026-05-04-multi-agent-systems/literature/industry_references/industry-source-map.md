## Search Notes

The current manuscript already cites most core academic systems. The missing
industry layer is not "more papers"; it is evidence that the field's center of
gravity has shifted toward deployable orchestration infrastructure:

- managed supervisors and subagents;
- handoffs and agents-as-tools;
- agent communication protocols;
- agent observability and trace formats;
- sandboxed cloud coding agents;
- parallel task portfolios under human review;
- context engineering and shared-state governance;
- enterprise control planes for agent ecosystems.

For a polished review article, cite industry posts sparingly. The strongest
approach is to use one or two sources per paragraph to support the historical
claim that production systems emphasize orchestration, context, sandboxes,
traces, and human governance, while keeping performance claims anchored in
papers and benchmarks.
