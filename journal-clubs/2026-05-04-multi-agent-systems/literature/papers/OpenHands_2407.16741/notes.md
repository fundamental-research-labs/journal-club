# Notes

## Why It Matters
OpenHands is an infrastructure paper for the agent literature: it makes "AI software developer" agents concrete as a runtime, UI, action log, sandbox, skills library, agent hub, delegation mechanism, and evaluation harness. It is useful because many later claims about coding agents, web agents, and multi-agent software work assume exactly this kind of substrate.

## When To Cite
Cite it when discussing open-source software-engineering agents, generalist agents that act through code and browsers, sandboxed agent runtimes, event-stream agent architectures, agent benchmark integration, agent-computer interfaces, OpenDevin/OpenHands as an artifact, or OpenHands-based experiments in later work.
