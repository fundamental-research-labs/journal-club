# Notes

## Why It Matters
MIRROR is useful because it separates two kinds of reflection that are often conflated in agent papers: pre-execution self-checking inside an agent and post-execution learning across a trajectory. The paper gives a concrete multi-agent tool-use design where reflection gates planner outputs, tool calls, and final answers, then backs the design with benchmark and ablation evidence.

## When To Cite
Cite this paper for multi-agent tool-learning systems, pre-action or pre-handoff reflection, comparisons to Reflexion-style post-execution learning, memory-backed reflection loops, and benchmark evidence on StableToolBench or TravelPlanner. It is especially relevant when arguing that agent reflection should prevent errors before tool execution, not only recover after failed tool calls.
