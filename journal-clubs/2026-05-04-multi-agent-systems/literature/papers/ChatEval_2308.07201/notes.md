# Notes

## Why It Matters
ChatEval is an early, concrete template for using multiple LLM agents as evaluators rather than as task workers. Its useful lesson is that evaluation quality can depend on deliberation design: role diversity, message visibility, voting or averaging, and debate length all change how closely model judgments track human annotations.

## When To Cite
Cite it for LLM-as-a-judge systems, multi-agent debate for evaluation, role-diverse referee prompts, communication strategies among evaluator agents, and empirical comparisons against single-agent LLM evaluators on FairEval and Topical-Chat.

## Key Terms
ChatEval; LLM-as-a-judge; multi-agent debate; debater agents; diverse role specification; one-by-one communication; simultaneous-talk; simultaneous-talk-with-summarizer; majority vote; average score extraction; FairEval; Topical-Chat; human alignment.
