# Notes

## Why It Matters

InternAgent is a useful representative of the "AI scientist" direction because it tries to close the full research loop: literature search, idea generation, method construction, code changes, experiment execution, debugging, and result-driven refinement. Its value for this corpus is less about any single task result and more about the system pattern: specialized agents, human feedback points, codebase review, and adaptive experimentation applied across both AI and science workloads.

## When To Cite

Cite when discussing autonomous scientific research, closed-loop research agents, AI4Science automation, LLM-based idea generation with empirical validation, human-in-the-loop scientific agents, or agent systems that must modify and debug real codebases rather than only write papers or proposals. It is also relevant as a comparator for AI Scientist, AI-Scientist-V2, DOLPHIN, AI-Researcher, Agent Laboratory, and AI Co-Scientist style systems.
