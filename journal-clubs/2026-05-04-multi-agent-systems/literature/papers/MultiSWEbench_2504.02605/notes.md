# Notes

## Why It Matters
Multi-SWE-bench is a useful corrective to Python-only confidence in software agents. It shows that issue resolving remains much harder once agents face Java, TypeScript, JavaScript, Go, Rust, C, and C++ repositories with different tooling, build systems, language semantics, and patch shapes. The paper is also valuable as a dataset-construction reference because it combines executable environments, test-transition filtering, and manual verification.

## When To Cite
Cite it when discussing multilingual SWE-agent evaluation, limitations of SWE-bench as a mostly Python benchmark, real-world issue-resolving benchmarks, automated program repair with LLMs, language-specific coding-agent failure modes, or RL data collection for software-engineering agents.
