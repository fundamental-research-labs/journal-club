# Notes

## Why It Matters
WorkArena is a useful benchmark for the gap between browser agents that can operate on simplified sites and agents that can reliably automate business software. Its main value is not just the task count, but the realistic UI friction: large observations, dynamic widgets, non-standard HTML, menus, forms, catalogs, and validation against actual task outcomes.

## When To Cite
Cite it when discussing enterprise web-agent benchmarks, ServiceNow-style workflow automation, browser agents for knowledge work, UI-assistant evaluation, BrowserGym, realistic web UI complexity, or evidence that current LLM agents still struggle with routine workplace software.
