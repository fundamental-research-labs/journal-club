# Notes

## Why It Matters
AgentCoder is an early, concrete example of multi-agent coding that gains leverage from role separation rather than open-ended agent chat. Its main lesson is practical: independent test generation plus local execution feedback can make iterative LLM code repair more effective and cheaper than heavier multi-agent coordination patterns on small programming benchmarks.

## When To Cite
Cite it for multi-agent code generation, LLM-generated tests, separating programmer and tester roles, executable feedback loops, HumanEval/MBPP pass@1 comparisons, or token-efficient alternatives to broad software-development agent simulations. Use more repository-level papers when the claim is about large codebases, merge conflicts, or collaborative branch integration.
