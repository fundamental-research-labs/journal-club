# Notes

## Why It Matters
GPTSwarm is a useful bridge between prompt engineering, agent frameworks, and automated architecture search. Its core move is to make the structure of an agent system explicit: operations become nodes, communication becomes edges, and both can be optimized instead of hard-coded. This makes it a natural citation for work that treats multi-agent coordination as a learnable orchestration problem rather than only a prompting or role-design problem.

## When To Cite
Cite it when discussing graph-based language agents, automatic optimization of agent communication topologies, node-level prompt optimization inside agent pipelines, or benchmark evidence for recombining COT/TOT/Reflexion/tool-use components. It is also useful when contrasting hand-designed multi-agent frameworks with systems that search over edge structure or optimize prompts locally.
