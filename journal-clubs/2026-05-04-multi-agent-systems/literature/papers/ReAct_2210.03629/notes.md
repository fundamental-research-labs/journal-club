# Notes

## Why It Matters
ReAct is one of the canonical early recipes for LLM agents: expose tools or environments through actions, keep natural-language reasoning in the trajectory, and let observations update the next step. It matters because it turned chain-of-thought from a static answer-generation device into a closed-loop pattern for retrieval, planning, and interactive task completion.

## When To Cite
Cite it when discussing reasoning-plus-acting agents, tool-use prompting, agent trajectories, grounding chain-of-thought in external observations, Wikipedia/API-assisted QA, early web agents, or few-shot LLM control in ALFWorld and WebShop. It is also useful as a baseline ancestor for later agent benchmarks that evaluate trajectories rather than single-turn answers.
