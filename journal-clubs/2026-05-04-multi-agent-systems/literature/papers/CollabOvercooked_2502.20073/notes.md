# Notes

## Why It Matters
Collab-Overcooked is a useful benchmark for separating "the team finished" from "the agents collaborated well." Its main value is the forced-collaboration setup: agents cannot simply solve the task independently because resources, action spaces, and task knowledge are split. The paper also gives process metrics and failure analyses that make collaboration breakdowns more inspectable than a final success rate alone.

## When To Cite
Cite it for LLM multi-agent collaboration benchmarks, Overcooked-style embodied agent evaluation, resource isolation and asymmetric task knowledge, process-oriented metrics for initiating/responding to collaboration, TES/ITES/PC/IC/RC, and attention-based analysis of collaboration failures.

## Key Terms
Collab-Overcooked; LLM-MAS; Overcooked-AI; ProAgent; resource isolation; asymmetric task knowledge; natural-language collaboration; Referential Action Trajectory (RAT); Trajectory Efficiency Score (TES); Incremental Trajectory Efficiency Score (ITES); Progress Completeness (PC); Initiating Capability (IC); Responding Capability (RC); attention misalignment; collaborative memory.
