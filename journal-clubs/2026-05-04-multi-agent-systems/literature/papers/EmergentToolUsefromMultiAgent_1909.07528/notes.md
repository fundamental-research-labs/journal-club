# Notes

## Why It Matters
This is a canonical example of multi-agent self-play generating an autocurriculum in an embodied environment. Its value is not just the hide-and-seek demo, but the mechanism: simple competitive rules, partial observability, manipulable objects, and sufficient scale can create a sequence of new tasks without explicitly rewarding tool use. It is also a useful cautionary paper because the same setup is sample-hungry, bounded by environment design, and vulnerable to simulator exploits.

## When To Cite
Cite it for emergent tool use, multi-agent autocurricula, embodied self-play, physically grounded MARL, team coordination from shared rewards, comparisons between self-play and intrinsic motivation, or transfer-based evaluation of open-ended RL progress.
