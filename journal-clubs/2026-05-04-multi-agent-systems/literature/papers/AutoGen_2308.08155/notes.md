# Notes

## Why It Matters
AutoGen is an early infrastructure paper for LLM agent systems that treats multi-agent coordination as a programmable conversation substrate rather than a one-off prompt pattern. It is especially useful because it combines several ingredients that later agent systems build on: role-specialized agents, tool and code execution, human participation, auto-reply loops, dynamic group chat, and application-level orchestration.

## When To Cite
Cite it when discussing AutoGen specifically, multi-agent LLM frameworks, conversation programming, conversable agents, human-in-the-loop agent workflows, tool-backed agents, code-executing agents, dynamic group chat, or examples of applying one agent framework across math, retrieval, online decision making, coding, and games.
