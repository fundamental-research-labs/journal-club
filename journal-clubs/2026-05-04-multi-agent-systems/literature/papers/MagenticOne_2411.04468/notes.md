# Notes

## Why It Matters
Magentic-One is a concrete, open-source reference point for generalist multi-agent systems: it shows how a central planner can coordinate specialized agents for web browsing, file handling, coding, and terminal execution without rewriting the team for each benchmark. It is also useful because the paper pairs positive benchmark results with ablations, log-derived failure analysis, safety discussion, and an evaluation harness designed for stateful agent runs.

## When To Cite
Cite it when discussing ledger-based orchestration, tool-centric multi-agent design, AutoGen-based agent systems, generalist web/file/code agents, AutoGenBench, or benchmark results on GAIA, AssistantBench, and WebArena. It is also a good citation for practical limitations of generalist agents: high cost and latency, incomplete modality/action support, weak verification, fixed team composition, and lack of cross-task learning.
