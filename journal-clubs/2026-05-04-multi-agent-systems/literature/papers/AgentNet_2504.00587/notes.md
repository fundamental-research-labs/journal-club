# Notes

## Why It Matters
AgentNet is a useful example of a decentralized design for LLM-based multi-agent systems. Rather than assuming a manager agent or a fixed workflow, it gives each agent local routing authority, local memory, and a mechanism for evolving collaboration links. The paper is most valuable as an architectural and empirical reference for self-organizing agent teams, especially when discussing scalability, specialization, and privacy-preserving collaboration.

## When To Cite
Cite it when discussing decentralized LLM multi-agent systems, DAG-based task routing, adaptive multi-agent coordination, RAG-style trajectory memory, autonomous agent specialization, evolutionary coordination, or comparisons against centralized frameworks such as MetaGPT and graph/workflow optimization frameworks such as GPTSwarm and AFLOW. Cite cautiously for privacy and fault tolerance: the paper motivates those benefits from the architecture, but its experiments mainly evaluate benchmark accuracy.
