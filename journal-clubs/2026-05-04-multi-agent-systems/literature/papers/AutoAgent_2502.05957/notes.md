# Notes

## Why It Matters
AutoAgent is a useful reference for the "agents build agents" direction: it treats LLM-agent development itself as an automated task, not just a developer API problem. The paper combines a generalist web/code/file agent stack with self-play customization, vector-backed file management, and workflow generation, making it relevant to both agent frameworks and agentic RAG.

## When To Cite
Cite it when discussing zero-code or natural-language agent development, automatic tool/agent/workflow generation, generalist agent stacks for GAIA-style tasks, self-debugging agent editors, event-driven LLM workflows, or agentic RAG systems that expose local files through vector-database tools.
