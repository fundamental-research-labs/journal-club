# Notes

## Why It Matters
MetaGPT is an early influential example of treating LLM-agent collaboration as workflow engineering rather than unconstrained conversation. Its main contribution is the idea that multi-agent coding systems need standardized artifacts, role responsibilities, scoped information flow, and executable feedback if they are going to reduce rather than amplify hallucinations.

## When To Cite
Cite it for SOP-based multi-agent software engineering, role-specialized LLM agents, structured document handoffs, publish-subscribe message pools, executable feedback for code generation, and early benchmark evidence that structured multi-agent workflows can outperform chat-style or general autonomous-agent baselines on software tasks.
