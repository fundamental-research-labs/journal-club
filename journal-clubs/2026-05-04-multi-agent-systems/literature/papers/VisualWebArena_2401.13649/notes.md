# Notes

## Why It Matters
VisualWebArena is a key benchmark for the shift from text-only web agents to multimodal browser agents. Its main contribution is not just adding screenshots: it forces agents to connect visual perception, page layout, user-provided images, natural-language goals, and executable browser actions in reproducible web environments.

## When To Cite
Cite it for visually grounded web-agent evaluation, multimodal browser automation, Set-of-Marks action grounding, execution-based evaluation of VLM agents, and evidence that current agents remain far below human performance on realistic visual web tasks.
