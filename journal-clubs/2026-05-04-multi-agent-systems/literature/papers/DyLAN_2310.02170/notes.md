# Notes

## Why It Matters
DyLAN is an early, concrete attempt to make multi-agent LLM systems task-adaptive instead of assuming that a fixed set of personas and fixed debate rounds will generalize. Its main contribution is the combination of dynamic communication topology, ranker-driven agent pruning, and an unsupervised contribution score for selecting a smaller task-oriented team.

## When To Cite
Cite it when discussing dynamic LLM-agent teams, agent selection, multi-agent communication structures, feed-forward agent networks, or efficiency/performance tradeoffs in agent collaboration. It is also useful as a baseline or contrast point for work on AutoGen-style frameworks, multi-agent debate, AgentVerse/CAMEL-style role teams, and studies of coordination overhead.
