# Notes

## Why It Matters
ChatDev is an early, influential example of using multiple role-specialized LLM agents as a software-development organization. Its lasting value is less the raw benchmark score and more the design pattern: make agents communicate through a constrained workflow, preserve intermediate artifacts across phases, and use review/test conversations to refine code.

## When To Cite
Cite it for LLM-based software-development agents, role-specialized multi-agent coding, chat-chain orchestration, communicative dehallucination, early agentic code-generation systems, or historical comparisons with MetaGPT, AutoGen, CooperBench, and later multi-agent coding benchmarks.
