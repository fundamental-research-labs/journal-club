# Notes

## Why It Matters
This is one of the clearest papers in the corpus treating multi-agent LLM collaboration as an inference-time scaling problem. Its value is less that MACNET is a finished system and more that it makes topology, memory flow, and scaling curves explicit design variables. It also gives a useful bridge between "more agents help" papers and later work showing that unconstrained coordination can fail.

## When To Cite
Cite it when discussing collaborative scaling laws, graph-structured LLM agent teams, topology effects in multi-agent collaboration, actor/critic role decomposition, artifact-only memory propagation, or inference-time alternatives to retraining larger models. It is also useful as background for claims that larger agent teams need constrained communication paths rather than global chat or naive majority voting.
