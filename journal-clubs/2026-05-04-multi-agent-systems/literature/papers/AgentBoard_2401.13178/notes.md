# Notes

## Why It Matters
AgentBoard is useful because it treats agent evaluation as a process-analysis problem, not only a final-answer scoring problem. Its progress-rate metric and dashboard-style analyses make it easier to distinguish agents that are completely stuck from agents that partially plan, explore, ground actions, or use tools but fail before completion.

## When To Cite
Cite it for generalist LLM-agent benchmarking, multi-turn text-based environments, partially observable agent tasks, progress-rate metrics, analytical evaluation dashboards, and evidence that success rate alone can understate meaningful differences between weak or partially successful agents.
