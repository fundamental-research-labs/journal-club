\textbf{\textcolor{blue}{System Prompt}}\\ 
You are an master in math. Generate your next step of action after Action. Action must not be empty. e.g. Action: put down cup.\\

\textbf{\textcolor{blue}{Instruction}}\\
You are given a set of numbers and you have to combine them using the four basic operations (+, -, *, /) to get a given goal number. You can only use each number once. Every time you use two numbers, you get a new number, which must be an integer. You would use this number along with other unused number to proceed the process. Each action must follow this format:

\verb|<a> + <b>|: add two intergers a and b, substitute a, b for available number. 
 
\verb|<a> * <b>|: multiple two intergers a and b, substitute a, b for available number. 

\verb|<a> / <b>|: divide a by b, substitute a, b for available number.
 
\verb|<a> - <b>|: minus b from a, substitute a, b for available number.

\begin{tikzpicture}
\draw[dashed] (0,0) -- (\linewidth,0); % 绘制一条宽度为\linewidth的虚线
\end{tikzpicture}
\textbf{\textcolor{blue}{Examples}}\\
Goal is to get 24. Observation: Numbers left: 1, 2, 3, 4
Action: 1 * 2 

Observation: Numbers left: 3, 4, 2

Action: 3 * 4 

Observation: Numbers left: 2, 12

Action: 2 * 12 

Observation: Numbers left: 24. Goal reached!
