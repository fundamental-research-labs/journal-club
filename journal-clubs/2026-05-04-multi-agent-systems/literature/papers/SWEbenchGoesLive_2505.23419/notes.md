# Notes

## Why It Matters
SWE-bench-Live is a strong citation for the argument that static coding benchmarks can overstate agent progress. It makes the evaluation target fresher, broader, and more operationally realistic by pairing recent GitHub issues with reproducible Docker images and test-transition validation. The result is also sobering: leading agent/model combinations remain under 20% resolved on the full benchmark in the paper's experiments.

## When To Cite
Cite when discussing live or contamination-resistant code benchmarks, SWE-bench extensions, repository-level issue resolution, automated benchmark construction, Dockerized evaluation environments, or evidence that current coding agents struggle with realistic multi-file bug fixes.
