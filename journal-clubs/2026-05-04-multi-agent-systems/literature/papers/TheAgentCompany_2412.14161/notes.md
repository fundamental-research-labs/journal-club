# Notes

## Why It Matters
TheAgentCompany is a useful benchmark for grounding debates about digital labor automation in tasks that resemble everyday company work: browsing internal systems, editing documents, running code, managing project data, and asking colleagues for missing information. Its main lesson is that current LLM agents can automate some well-scoped work, but long-horizon workflows with social context and messy web interfaces remain far from solved.

## When To Cite
Cite it when discussing benchmarks for LLM agents in realistic work environments, self-hosted enterprise-style evaluation, checkpoint-based task scoring, simulated colleagues, agent communication, workplace automation, or comparisons between coding-heavy tasks and broader office workflows.
