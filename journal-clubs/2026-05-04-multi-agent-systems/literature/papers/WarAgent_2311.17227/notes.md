# Notes

## Why It Matters
WarAgent is an early example of using LLM agents for social and historical simulation rather than productivity or benchmark task solving. Its main contribution is not that it predicts wars, but that it shows how to encode geopolitical actors with profiles, constrained diplomatic actions, partial observability, state-tracking artifacts, and counterfactual prompt edits.

The paper is also useful as a cautionary case: LLM social simulations are highly sensitive to model capability, prompt design, anonymization, and evaluation choices. The authors explicitly argue for interpreting results as suggestive rationales rather than verified conclusions.

## When To Cite
Cite it for LLM-based multi-agent social simulation, historical conflict simulation, country-agent role-play, Board/Stick state tracking, anonymization to reduce historical recall, counterfactual trigger experiments, and limitations of using LLM agents for policy-relevant social science.
