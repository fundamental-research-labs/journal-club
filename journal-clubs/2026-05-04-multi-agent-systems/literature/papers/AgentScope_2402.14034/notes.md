# Notes

## Why It Matters
AgentScope is a useful framework reference for the early LLM multi-agent stack: it makes message exchange, workflow composition, fault handling, tools, RAG, multimodal data, UI monitoring, and distributed deployment part of one platform. Its value for the corpus is less about empirical performance and more about identifying the infrastructure concerns a practical multi-agent platform must absorb.

## When To Cite
Cite when discussing LLM multi-agent frameworks, message-passing orchestration, platform-level fault tolerance for LLM agents, no-code or low-code agent workflow construction, multimodal/tool/RAG support in agent systems, or local-to-distributed migration for agent applications.

## Key Terms
AgentScope; message exchange; `Msg`; agent `reply` and `observe`; workflow; pipeline; message hub; service toolkit; ReAct agent; rule-based correction; `parse_func`; `fault_handler`; `max_retries`; knowledge bank; RAG object; URL-attached multimodal messages; actor-based distributed mode; placeholder message; AgentScope Studio; AgentScope Workstation.
