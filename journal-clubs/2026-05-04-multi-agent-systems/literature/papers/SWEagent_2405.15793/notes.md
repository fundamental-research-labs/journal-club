# Notes

## Why It Matters
SWE-agent is an early, influential example of treating the interface around a coding model as an object of study. Its central lesson is that agent performance is not just a property of the base LM: search result shape, file-view context, edit granularity, syntax guardrails, and history compression can all change whether the model can make progress on real repositories.

## When To Cite
Cite it when discussing agent-computer interfaces, autonomous software-engineering agents, SWE-bench baselines, repository-level bug fixing, interface/tool ablations for coding agents, or the role of execution feedback and edit guardrails in LM agent workflows.
