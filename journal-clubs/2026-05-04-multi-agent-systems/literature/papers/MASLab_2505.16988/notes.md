# Notes

## Why It Matters
MASLab is useful because it treats multi-agent research as an implementation and evaluation problem, not just a prompting problem. It gives researchers a common place to compare agent-team designs while controlling for preprocessing, model settings, tools, and answer evaluation. The paper is also a cautionary reference: method rankings can shift under different evaluators, and MAS failures often come from mundane system issues such as schema adherence and brittle tools.

## When To Cite
Cite it when discussing unified codebases for LLM-based multi-agent systems, reproducible MAS comparisons, evaluation protocol sensitivity, broad MAS benchmark landscapes, tool-augmented agent evaluation on GAIA, or failure modes caused by output formatting and tool use.
