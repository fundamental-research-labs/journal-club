# Notes

## Why It Matters
AgentRxiv is a concrete attempt to make autonomous research cumulative rather than one-shot. Its main contribution is not a new solver by itself, but an artifact-sharing loop where agent-generated papers become searchable inputs to future agent laboratories. The paper is useful because it combines an optimistic result - shared prior work and parallel labs can improve benchmark-driven discovery - with a candid account of hallucination, reward hacking, verification, cost, and novelty limits.

## When To Cite
Cite it when discussing collaborative autonomous research, agent-generated scientific papers, shared memory or retrieval layers for research agents, benchmark-driven discovery of prompting techniques, Agent Laboratory extensions, or the cost and reliability trade-offs of parallel agent labs.

AgentRxiv; autonomous research; Agent Laboratory; agent-generated preprint server; cumulative discovery; asynchronous artifact sharing; SentenceTransformer retrieval; MATH-500; Simultaneous Divergence Averaging (SDA); parallel agent laboratories; reward hacking; hallucinated results; human verification.
