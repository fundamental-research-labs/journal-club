\section{Problem Overview}\label{sec:problem-overview}

\autoref{tab:problem-overview} lists all 20 problems in SlopCodeBench. Problems span CLIs, REST APIs, DSL interpreters, and file-processing pipelines. Each begins with a focused deliverable and grows through iterative specification refinement, mirroring real software evolution from prototype to production system. Four problems produce HTTP services; the remaining sixteen are command-line tools.
