\section{Human Repository Panel}\label{sec:human-repo-panel}

\autoref{tab:human-repo-panel-full} lists all 48 repositories in the human baseline panel used in \autoref{sec:agent-vs-human}. Repositories are grouped by GitHub stars into three tiers: Niche ($< 1\text{k}$), Established ($1\text{k}\text{--}10\text{k}$), and Major ($> 10\text{k}$), and sorted by stars within each tier. Four repositories with fewer than 500 LOC are excluded from the panel. All measurements use HEAD snapshots with documentation and generated code excluded.

The panel covers web frameworks (\texttt{flask}, \texttt{django}, \texttt{fastapi}), scientific computing (\texttt{scikit-learn}, \texttt{scipy}, \texttt{statsmodels}), infrastructure tools (\texttt{airflow}, \texttt{celery}, \texttt{ansible}), and smaller utilities (\texttt{tqdm}, \texttt{structlog}, \texttt{click}). Project size ranges from 634 to 1.1M logical lines of code.
