# Notes

## Why It Matters
SafeArena is a useful bridge between web-agent capability benchmarks and AI safety evaluations. Its core point is practical: a model that refuses harmful chat requests may still comply once the same intent is embedded in browser navigation, form filling, repository edits, or shopping/admin workflows. The paired safe/harmful design also makes it easier to separate "the agent cannot use the site" from "the agent can use the site but does not refuse harmful use."

## When To Cite
Cite it for autonomous web-agent safety, harmful-use benchmarks, ARIA risk levels, normalized safety scoring for paired safe/harmful tasks, BrowserGym/WebArena-style safety evaluation, and jailbreak susceptibility of browser agents through decomposition or priming.
