# Notes

## Why It Matters
AndroidWorld is a strong citation for realistic mobile UI-agent evaluation. It provides executable Android tasks, parameterized goal generation, and ground-truth reward checks from device state, making it more useful than static demonstration datasets when the research question is whether an agent actually completed a mobile task.

## When To Cite
Cite it for Android or mobile computer-control benchmarks, online evaluation of UI agents, device-state reward design, parameterized task generation, MobileMiniWoB++, and baseline evidence that current agents remain far below human reliability on real app workflows.

## Key Terms
AndroidWorld; M3A; MobileMiniWoB++; AndroidEnv; Android Debug Bridge; accessibility tree; Set-of-Mark; device-state rewards; task parameterization; initialization/success-check/teardown; Android Emulator; UI grounding; robustness across seeds.
