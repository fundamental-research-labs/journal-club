# Notes

## Why It Matters
This paper is an early, concrete formulation of debate as a way to break an LLM out of self-confirming reasoning loops. Its main value for the corpus is not just that multi-agent prompting improves benchmark scores, but that it names a failure mode of self-reflection, operationalizes divergent thinking through opposing agents, and studies practical knobs such as judge stopping, debate intensity, debater count, and judge bias.

## When To Cite
Cite it when discussing multi-agent debate for reasoning, divergent chain-of-thought prompting, limitations of self-reflection, commonsense translation ambiguity, counter-intuitive arithmetic reasoning, adaptive debate stopping, or LLM judge bias in mixed-model agent systems.

## Key Terms
Degeneration-of-Thought (DoT); Multi-Agent Debate (MAD); divergent thinking; self-reflection; tit for tat debate; affirmative debater; negative debater; judge agent; discriminative mode; extractive mode; adaptive break; Common MT; commonsense machine translation; Counter-Intuitive Arithmetic Reasoning (CIAR); LLM-as-judge bias; Self-BLEU diversity.
