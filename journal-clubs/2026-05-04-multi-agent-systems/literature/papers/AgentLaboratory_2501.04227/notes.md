# Notes

## Why It Matters
Agent Laboratory is a concrete, end-to-end example of LLM agents being used as research assistants across literature review, planning, code generation, experiment execution, interpretation, and report writing. Its most useful contribution is not that it proves autonomous science is solved, but that it gives a reproducible workflow and human-centered evaluation for where current research agents help and where they still fail.

## When To Cite
Cite it when discussing LLM agents for scientific discovery, automated machine-learning research workflows, human-in-the-loop research copilots, autonomous report generation, `mle-solver`-style ML coding loops, or the gap between automated paper review and human evaluation.
