# Notes

## Why It Matters
AgentsNet is a clean benchmark for a question that ordinary agent benchmarks often blur: can LLM agents coordinate through a network, using only local messages, to produce a globally valid outcome? Its use of distributed-computing tasks makes the coordination requirement explicit, scalable, and theoretically interpretable.

## When To Cite
Cite it for scalable multi-agent LLM evaluation, graph-topology-aware agent coordination, local message-passing protocols, distributed-systems-inspired benchmarks, leader election or consensus among LLM agents, and evidence that larger agent networks can sharply increase coordination difficulty.

## Key Terms
AgentsNet; LOCAL model; synchronous message passing; graph coloring; minimal vertex cover; maximal matching; leader election; consensus; small-world graphs; scale-free graphs; Delaunay graphs; strict binary network-level success; soft score; strategy coordination.
