# Notes

## Why It Matters
OMAC is useful because it turns MAS design from a hand-authored prompt/topology exercise into an explicit optimization problem. Its main contribution is the unified treatment of agent functionality and collaboration structure: the same supervised contrastive loop can tune agents, add agents, select teams, select step participants, or route messages.

## When To Cite
Cite it when discussing automated optimization of LLM-based multi-agent systems, prompt/controller optimization for MAS, dynamic agent selection, communication routing, or empirical comparisons against DyLAN, ADAS, AFlow, AgentVerse, LLM Debate, and CodeT on HumanEval, MMLU, MATH, MBPP, or GAIA.

## Key Terms
OMAC; Semantic Initializer; Contrastive Comparator; positive-negative performance pairs; Fun-1; Fun-2; Str-1; Str-2; Str-3; candidate agent selection; dynamic agent participation; communication-flow routing; multi-step collaboration; information-flow graph; DyLAN; ADAS; AFlow.
