\begin{abstract}
  The current mainstream approach to train natural language systems is
  to expose them to large amounts of text. This passive learning is
  problematic if we are interested in developing \emph{interactive}
  machines, such as conversational agents. We propose a framework for
  language learning that relies on multi-agent communication. We study this learning in the context of referential games.   In these games, a sender and a
  receiver see a pair of images. %One of the images at random is
  %designed as the `target'. The sender is informed of the choice, but
  %receiver is not. The sender sends a message to send to the receiver,
  %and the receiver must rely on it to identify the target. 
   The sender is told one of them is the target and is allowed to send a message from a
   fixed, arbitary vocabulary to the receiver. 
   The receiver must rely on this message to identify the target. 
   Thus, the  agents develop their own language interactively out of the need to
  communicate. We show that two networks with simple
  configurations are able to learn to coordinate in the referential
  game. We further explore how to make changes to the game environment to cause the ``word meanings'' induced in
  the game to better reflect intuitive semantic properties of the images. In addition, we present a simple strategy for grounding the
  agents' code into natural language. 
  Both of these are necessary steps towards developing machines that are able to
  communicate with humans productively. %
% We propose a framework for language learning based on referential games. In a referential game a sender and a receiver each see a pair of images. The sender is told that one of them is the target and is allowed to send a message to the receiver. The receiver must use the contents of the message to try to infer which of the two images the sender is referring to. Thus, instead of being passively exposed to large amounts of natural text, our learners start from a tabula rasa and develop their own language from the need to communicate in order to succeed. We show that two networks with a simple configuration are able to learn to coordinate in the referential game, however, it seems like at a baseline these networks use very low level properties of the images as the referents (eg. ``the brighter one''). In a series of experiments we explore ways to modify the game to make the language which emerges more reflect the high level properties of the image. Finally, we discuss strategies for grounding the induced language into natural language, necessary for having machines communicating with humans.
\end{abstract}
