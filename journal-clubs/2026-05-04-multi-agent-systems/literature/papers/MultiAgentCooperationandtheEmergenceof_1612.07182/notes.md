# Notes

## Why It Matters
This is an early neural emergent-communication result showing that cooperative pressure alone can produce a task-useful discrete protocol between agents. It is especially useful because it goes beyond "agents can coordinate" and asks whether the resulting symbols align with semantic categories or human-interpretable words. The paper frames language as a functional coordination tool, not just a supervised prediction target.

## When To Cite
Cite it for visual referential games, emergent communication in neural multi-agent systems, sender-receiver signaling games, discrete communication bottlenecks, semantic analysis of emergent symbols, environment design for more abstract communication, and hybrid interactive/supervised grounding of agent protocols.
