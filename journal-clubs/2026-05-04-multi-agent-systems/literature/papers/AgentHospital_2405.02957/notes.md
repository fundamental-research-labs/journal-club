# Notes

## Why It Matters
Agent Hospital is a concrete example of environment-driven agent improvement: instead of only prompting a medical LLM or organizing a panel of agents, it builds a simulated hospital where doctor agents repeatedly treat generated patients and accumulate reusable case memories and failure-derived principles. It is especially relevant for the corpus because it combines multi-agent simulation, synthetic data generation, RAG memory, and claims about virtual-to-real transfer.

## When To Cite
Cite this paper when discussing LLM-powered hospital simulacra, synthetic patient generation, self-evolving medical agents, MedAgent-Zero, SEAL, medical case/experience memories, or MedQA evaluations that compare evolved agents with CoT, MedAgents, and Medprompt. Cite cautiously for healthcare impact: the evidence is from simulation and exam-style benchmarks, not clinical deployment.

## Key Terms
Agent Hospital; Simulacrum-based Evolutionary Agent Learning (SEAL); MedAgent-Zero; patient agent; doctor agent; nurse agent; virtual patient; medical case base; experience base; validated reflection; retrieval-augmented generation; medical examination selection; diagnosis; treatment plan recommendation; MedQA.
