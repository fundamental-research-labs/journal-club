# Notes

## Why It Matters
Mind2Web is a core early benchmark for generalist browser agents because it moves beyond toy websites toward real web pages, high-level user goals, and explicit generalization splits. It is especially useful for studying the grounding problem: the model may understand the task, but still has to map that intent onto noisy DOM structures and page-specific interaction logic.

## When To Cite
Cite it when discussing web-agent benchmarks, natural-language browser automation, offline evaluation with real webpage snapshots, DOM-element grounding, generalization to unseen websites or domains, and candidate-filtering pipelines that make large webpages tractable for LLMs.

## Key Terms
Mind2Web; MindAct; web agent; generalist web agent; high-level task description; target element; operation; DOM grounding; candidate generation; action prediction; multiple-choice action selection; cross-task split; cross-website split; cross-domain split; offline web evaluation; Playwright annotation.
