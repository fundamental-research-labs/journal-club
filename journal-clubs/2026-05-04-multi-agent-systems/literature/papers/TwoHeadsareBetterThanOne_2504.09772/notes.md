# Notes

## Why It Matters
This paper is useful for separating two levers in multi-agent reasoning: train the base model on collaborative traces, then add a controller that adapts agent count, discussion depth, and token budget at test time. Its main contribution is not a new MAS framework from scratch, but a recipe for making an existing framework, AgentVerse, benefit from learned collaboration and dynamic orchestration.

## When To Cite
Cite it for adaptive test-time scaling in multi-agent systems, supervised fine-tuning on multi-agent reasoning traces, CEO/controller agents for MAS coordination, AgentVerse-based reasoning evaluations, and the M500/M1-32B recipe. It is also a useful citation when arguing that multi-agent gains depend on training and orchestration details rather than simply adding more agents.
