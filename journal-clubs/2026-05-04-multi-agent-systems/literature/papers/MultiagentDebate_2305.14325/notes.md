# Notes

## Why It Matters
This is one of the clean early demonstrations that multi-agent LLM inference can improve answers without training, retrieval, tools, or access to model internals. Its core idea is simple: sample multiple reasoning traces, expose each agent to the others' traces, and let agents revise toward consensus. That makes it a useful reference point for later agent-ensemble, critique, and debate systems.

## When To Cite
Cite it for prompt-only multi-agent debate, black-box LLM answer refinement, consensus prompting, factuality checks through multiple model instances, and experiments varying agent count or debate rounds. It is also useful as a baseline citation when contrasting debate-style QA improvement with harder collaborative-agent settings that require shared state, planning, or code integration.
