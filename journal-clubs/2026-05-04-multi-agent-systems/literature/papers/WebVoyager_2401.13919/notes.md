# Notes

## Why It Matters
WebVoyager is an early, concrete blueprint for multimodal web agents that operate on live websites rather than simplified simulators. Its main contribution is not just a stronger browser agent, but a package of design choices: screenshot-first observation, numeric element marking, a compact browser action space, end-to-end task-success evaluation, and GPT-4V-based trajectory judging checked against humans.

## When To Cite
Cite it for end-to-end web agents, multimodal browser automation, live-website evaluation, screenshot-plus-DOM-element observations, set-of-mark prompting for UI control, and automatic evaluation of open-ended web-agent trajectories.

## Key Terms
WebVoyager; large multimodal model; GPT-4V; live web navigation; Selenium browser environment; set-of-mark prompting; interactive element labels; screenshot observation; accessibility tree baseline; task success rate; GPT-4V automatic evaluator; trajectory evaluation; navigation stuck; visual grounding issue.
