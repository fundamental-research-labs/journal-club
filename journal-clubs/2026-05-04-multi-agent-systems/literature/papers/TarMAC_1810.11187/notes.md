# Notes

## Why It Matters
TarMAC is a foundational learned-communication architecture for MARL because it separates message content from message routing. Instead of treating communication as a global broadcast or pooled vector, it gives each sender and receiver a differentiable mechanism for deciding which messages are relevant while keeping decentralized execution. That makes it a useful bridge between emergent communication, attention-based routing, and practical coordination in partially observable multi-agent tasks.

## When To Cite
Cite TarMAC when discussing targeted inter-agent communication, attention-based message routing, continuous emergent communication, multi-round communication before action selection, centralized-training/decentralized-execution communication architectures, or benchmarks involving SHAPES, traffic junctions, House3D, and Predator-Prey communication variants. It is also a good citation when contrasting "whom to communicate with" against IC3Net-style "when to communicate" gating.
