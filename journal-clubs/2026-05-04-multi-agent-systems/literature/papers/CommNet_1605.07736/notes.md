# Notes

## Why It Matters
CommNet is an early, clean example of learning communication end-to-end inside a cooperative multi-agent controller. Its main contribution is making communication a differentiable continuous vector channel, which links MARL coordination, emergent communication, and neural message passing.

## When To Cite
Cite it for learned communication in multi-agent reinforcement learning, differentiable inter-agent communication, continuous communication protocols, early neural emergent communication, or baselines for cooperative partially observed tasks such as traffic and combat. It is also useful when connecting multi-agent controllers to graph neural networks or message-passing architectures.

## Key Terms
CommNet; Communication Neural Net; continuous communication; broadcast communication; local communication; fully cooperative agents; shared reward; policy gradient; permutation invariance; dynamic agent count; message passing; lever pulling; traffic junction; combat task; bAbI.
