# Notes

## Why It Matters
GAIA became a reference point for evaluating general AI assistants because it makes a narrow but important claim measurable: can an assistant reliably complete ordinary, open-world, tool-heavy tasks and return an exact answer? Its value is that the final answer is easy to grade while the route to that answer may require search, file handling, multimodal perception, coding, and multi-step reasoning.

## When To Cite
Cite GAIA when discussing general-assistant benchmarks, tool-use evaluation, web-browsing agents, multimodal task execution, exact-match grading for open-world tasks, benchmark contamination mitigation, or the gap between human reliability and frontier assistants on simple but operationally demanding questions.

## Key Terms
GAIA; general AI assistant; factoid answer; quasi-exact match; tool use; web browsing; multimodality; diverse filetype reading; coding capability; source of truth; Level 1/2/3 questions; leaderboard split; benchmark contamination; open-world evaluation.
