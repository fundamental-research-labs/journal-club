# Notes

## Why it matters

MemMA is useful as a memory-system architecture paper: it treats memory as a cycle that needs planning, retrieval diagnosis, and local repair, not just a vector store plus summarizer.

## When to cite/use

Cite for memory-augmented agents, planner-worker memory coordination, iterative retrieval, long-horizon conversational QA, and probe-and-repair approaches to memory maintenance.

## Key terms

- MemMA
- memory cycle
- Meta-Thinker
- Memory Manager
- Query Reasoner
- in-situ self-evolution
- probe QA
