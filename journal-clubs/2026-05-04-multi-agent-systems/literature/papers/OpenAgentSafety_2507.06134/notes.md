# Notes

## Why It Matters
OpenAgentSafety is a useful anchor for agent safety work because it moves beyond static refusals and simulated APIs. It evaluates what tool-using agents actually do in sandboxed environments with files, browsers, terminals, code execution, local web apps, and social pressure from secondary actors. The main lesson is that safety failures often emerge from procedural context, authorization, hidden intent, and multi-turn state, not only from obviously malicious prompts.

## When To Cite
Cite it for realistic LLM-agent safety benchmarks, tool-use safety evaluation, multi-turn and multi-user agent tasks, hybrid rule-based plus LLM-judge evaluation, NPC-mediated social manipulation, and evidence that benign requests can still trigger unsafe agent behavior.
