# Notes

## Why It Matters
MemGPT is an early, concrete blueprint for LLM agents with explicit memory management. Its importance is not just "add retrieval"; it gives the model control over when to save, evict, search, paginate, and chain memory operations, using an operating-system analogy that remains useful for later agent-memory designs.

## When To Cite
Cite it when discussing virtual context, agent memory hierarchies, persistent conversational memory, function-calling agents that manage their own context, retrieval beyond fixed prompt limits, or OS-inspired designs for LLM systems.
