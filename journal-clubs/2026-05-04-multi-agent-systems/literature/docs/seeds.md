# Seed Papers

Papers that serve as starting points for citation-graph expansion. This is a trend-biased 100-paper seed set for multi-agent literature: recent LLM-based multi-agent systems are intentionally overrepresented, while older MARL/MAS work is kept as conceptual anchoring rather than allowed to dominate by citation age.

Seed roles:

- `core`: directly about LLM-based multi-agent systems, collaboration, debate, delegation, societies, or orchestration
- `trend`: recent high-signal LLM-agent work included to track where the field is moving
- `bridge`: single-agent, benchmark, software-agent, or tool-use paper that materially shapes multi-agent systems
- `anchor`: pre-LLM MARL, emergent communication, or classical MAS foundation
- `survey`: field-organizing survey useful for snowball expansion

## Current Balance

- 33 core LLM multi-agent papers
- 18 trend papers, mostly 2024-2026
- 32 bridge papers for agent benchmarks, software agents, web/computer-use agents, memory, and evaluation methodology
- 15 anchor papers from pre-LLM MARL/emergent communication/classical multi-agent evaluation
- 2 surveys

Temporal balance:

- 2023-2026: 83 papers
- 2024-2026: 63 papers
- 2025-2026: 38 papers
- Pre-2020: 13 papers

This balance is intentional: the seed set is for discovering the top-100 literature around LLM-based multi-agent agents, not for ranking all historical multi-agent systems by lifetime citations.
