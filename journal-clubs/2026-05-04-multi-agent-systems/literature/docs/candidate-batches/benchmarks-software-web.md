## Coverage Notes

- Covers agent evaluation, software-engineering agents, web/computer/mobile-use agents, tool/function calling, and safety/reliability benchmarks.
- Includes central seeds when they are anchor papers for this scope, but most rows are additional candidates absent from the current `docs/candidates.md`.
- Prioritizes arXiv IDs and official benchmark/venue IDs; a few infrastructure artifacts use benchmark names, OpenReview IDs, or venue identifiers where arXiv IDs were not evident.
- Recent 2025-2026 benchmarks such as `Terminal-Bench` and `Mobile-Bench-v2` are included as watchlist items because adoption and stability need follow-up.
- Older bridge benchmarks such as `World of Bits`, `WebGPT`, `HumanEval`, and `APPS` are included only where they directly shaped current agent evaluation practice.
